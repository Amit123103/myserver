Quick Reference

🔑 API Keys

node cli/keys.js create "App Name"
node cli/keys.js list
node cli/keys.js revoke <ID>

💾 Backups

npm run backup
npm run backup:verify
node cli/backup.js restore <file>

🔒 Certificates

npm run certs:ca
npm run certs:server
node cli/certs.js trust

🖥️ Service

# Start / Stop / Status
npm run supervisor
Start-ScheduledTask -TaskName "MyServer_Daemon"
Stop-ScheduledTask -TaskName "MyServer_Daemon"

🌐 Deploy via cURL

curl -k -X POST https://myserver.local/api/v1/projects/deploy \
  -H "x-api-key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My App",
    "slug": "my-app",
    "html": "<h1>Hello!</h1>"
  }'

📂 Deploy via Folder

# Simply copy files into:
# ./public/projects/my-app/
#   ├── index.html
#   ├── style.css
#   └── app.js
# Then visit: https://myserver.local/projects/my-app/
